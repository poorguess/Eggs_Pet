# 宠物换脸使用与验证

主开发项目：`D:/Godot_projects/1/Eggs_Pet`。参考项目未修改。

## 玩家操作

运行主岛，点原右下角拍照按钮，打开独立换脸界面。

1. 左侧始终预览角色动画第 0 帧。右侧点“拍照 / 选择自拍”，确认后沿用原相机或文件选择流程。

   验证已有素材时可直接点“上传已抠图五官（本地预览）”，选择透明 PNG/WebP。此入口不拍照、不调用生图服务；紧裁剪素材会等比补透明留白，随后使用相同的调节与应用流程。
2. 确认自拍后上传到配置的图生图服务。结果必须是透明的眉眼、鼻、嘴贴图；不能包含肤色脸板、头发和身体。
3. 调节水平/垂直位移、整体大小、宽高比例和旋转。默认等比，保留生成图内部五官间距；宽高比例是用户主动拉伸。
4. 点击“应用到宠物”才保存并替换外貌。返回主岛后仍播放原序列动画，五官跟随帧和朝向。再次打开可以继续调节，无须重新上传。
5. 取消、模型返回不合格、网络或保存失败均保留原外貌。重新开始游戏会清除已保存的五官外貌。

PNG 与调节参数分别存入 `user://pet_features_<编号>.png` 和 `user://pet_face_profile.json`。JSON 最后替换，避免失败时覆盖旧图。自拍沿用原流程暂存内存，不新增照片存盘逻辑。

## 游戏内服务配置

换脸界面点击“配置生图服务 / API Key”。默认地址为 `https://huniuai.token6688.com/v1`。填写 Key 后，可点击“测试连接 / 获取模型列表”；此操作仅 GET `/models`，不生成图片。选择服务商支持图片编辑的模型，或手动输入模型名，再点“保存并使用”。

配置保存至本机 `user://face_api.cfg`，Key 在界面中隐藏显示；保存后立即刷新 FaceApi，无需重启。实际图片请求发送至 `/images/edits`，沿用内嵌五官提示词。模型列表成功仅说明连接及鉴权通过，不保证所选模型支持图片编辑。

本次已验证服务的未鉴权请求返回 HTTP 401（要求 Bearer Token）。没有使用用户 Key，真实鉴权和生图需在游戏内填写后验证。

## 开发者标注

插件已在主项目启用。Godot 编辑器底部打开 **Face Contour**。

- 默认载入 `res://assets/pets/face_tracks/character1_walk.tres`，包含当前 33 帧的 12 点轮廓。
- 点 0 为额头顶部，随后沿屏幕顺时针。相同编号在所有帧必须代表同一位置；不要逐帧重新排序。
- 拖动已有点，或先选点编号再点击目标位置；勾“拖动整个轮廓”可整体移动。切换帧继续编辑。
- “复制前一帧”会生成当前关键帧；清除非第 0 帧后，用邻近帧插值。首尾空缺沿用最近帧。背面/遮挡用隐藏五官选项。
- 保存前会校验点数、顺序、自交、越界、退化及插值帧。错误只显示在插件面板，不更改游戏其他模块。
- 新建支持规则 PNG 序列图与 SpriteFrames.tres。新建时设置 4–64 点；先标首帧，再复制并修正后续帧。当前运行时 Pet 使用规则 Sprite2D 序列。
- 旧三点 `.tres` 可把完整文件路径填入“轨迹路径”后专门导入。导入仅生成椭圆草稿，源文件不执行、不覆盖。须校正并另存；它不是自动恢复的真实轮廓。

默认数据采用当前图片的浅色面部区域径向采样，已检查能用于当前角色；仍需美术最终逐帧复核。点数增加不能弥补错误对应关系。当前方案是 2D 网格变形，不承诺由正面图自动合成转头后的另一侧五官。

## 模块边界

| 模块 | 职责 |
|---|---|
| `scripts/face/face_track.gd` | 运行时轮廓资源、校验、插值 |
| `scripts/face/face_mesh.gd` | 均值坐标网格变形，UV 保持首帧对齐 |
| `scripts/face/face_overlay.gd` | 跟随 Sprite2D 帧、镜像和局部坐标 |
| `scripts/face/face_profile.gd` | 调节参数与独立外貌保存 |
| `scripts/face/face_image.gd` | 洋红抠图及透明度检查 |
| `scripts/face/face_prompt.gd` | 强制内嵌的五官生成协议 |
| `scenes/face_customizer.tscn` | 独立预览/调节界面 |
| `addons/face_track_editor` | 仅编辑器标注工具、导出排除 |

主岛只负责入口、照片采集、生图回调和应用信号；养成数值和小游戏规则不变。旧整身图片与圆头像存档继续可读，应用新五官后恢复序列动画显示。

## 导出

Android 预设显式排除 `addons/face_track_editor/*`、测试、文档和构建临时文件。插件的 ExportGuard 同时剥离自身在 `editor_plugins/enabled` 的路径，导出结束恢复编辑器内存设置，不写改磁盘项目设置。资源脚本位于 `scripts/face/`，不依赖插件。

新建导出预设时同样排除插件目录；保留插件启用以便 ExportGuard 自动移除启用记录。当前不修改其他插件的导出行为。
