# 五官贴图生成协议

当前内嵌提示词见 `scripts/face/face_prompt.gd` 的 `PetFacePrompt.TEXT`。

新链路只上传自拍，生成眉毛、双眼、鼻子和嘴巴的单张透明正方形 PNG。保留个人五官特征与自然间距，不生成肤色面片、头发、耳朵、身体或整个角色。五官组合居中，边缘留透明空间。

现有 `/images/edits` 接口使用 `prompt` 字段，没有聊天接口的 system role；代码将内嵌应用指令强制传入该字段。旧 `face_api.cfg` 中的 `prompt` 与 `character_ref` 不再决定生成内容，连接地址、密钥、model、size、quality 仍按原配置读取。建议 size 配置为服务支持的正方形尺寸。

优先要求真实 alpha。若上游不能输出透明，只允许纯洋红 #FF00FF 底色，客户端清除该颜色，包括五官之间的空隙；禁止猜测并删除肤色、白色或黑色，以免损坏眼白及五官。

客户端会拒绝空图、低分辨率、透明面积不足和边缘残留。上述检查不等于模型语义识别；生成了较小肤色面片时，仍需要用户在预览中拒绝并重试。生成失败不替换现有外貌。

完整模块设计、操作方式与测试限制见 [face_customization.md](face_customization.md)。
