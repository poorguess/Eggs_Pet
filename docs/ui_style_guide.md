# 蛋岛 UI 设计系统 ·「糖果岛」

> 版本 v1.0 · 2026-09-09 · 适用 Godot 4.7 全代码绘制 UI（无 Control 主题文件，所有组件用 `_draw()` 实现）
> 定位：移动端 2D 模拟养成小游戏。风格关键词：**糖果、Q 弹、卡通、治愈系养成**。
> 参考语言：《蛋仔派对》《开心消消乐》《旅行青蛙》的界面质感——圆、软、亮、弹。

---

## 1. 设计原则

1. **圆**：一切可交互元素都是圆或全圆角。锐角在本游戏中视为 bug。
2. **软**：投影永远带色相、低透明度，禁止纯黑投影。面板像棉花糖，不像玻璃。
3. **亮**：高明度、中饱和的糖果色；深色只用于文字和描边，不做大色块。
4. **弹**：所有点击都有"捏软糖"式的压缩回弹反馈；弹窗以弹簧动画出现。
5. **少**：一屏一个主动作。主界面唯一主按钮 = 相机。其余信息降级为"条、签、字"。

## 2. 色彩体系（Tokens）

| Token | 色值 | 用途 |
|---|---|---|
| `cream` | `#FFF9EF` | 面板/卡片底色（棉花糖白，禁用纯白 #FFFFFF） |
| `cream_dark` | `#F5E9D5` | 面板内凹槽、进度条底槽 |
| `ink` | `#5B4A3F` | 主文字（深可可，禁用纯黑 #000000） |
| `ink_soft` | `#A08B7C` | 次要文字/提示文字 |
| `candy_pink` | `#FF6B8A` | **唯一主强调色**：主按钮、相机 FAB 描边、关键 CTA |
| `candy_pink_dark` | `#E14C6D` | 粉按钮底边（3D 厚度）、按压态 |
| `sky` | `#4FB7FF` | 次强调：加速按钮、信息型标签 |
| `sky_dark` | `#2E96E8` | 蓝按钮底边 |
| `mint` | `#5CD6A2` | 成功/确认（✓） |
| `mint_dark` | `#3DBB85` | 绿按钮底边 |
| `lemon` | `#FFD23F` | 高亮、星星、孵化倒计时数字 |
| `danger` | `#FF5A5A` | 错误/取消（✗）、API 失败提示标题 |
| `shadow_warm` | `#5B4A3F @ 18%` | 面板投影（带可可色相） |

**状态条四色**（与场景语义绑定，全游戏一致）：
温度 `#FF9F43` 橙 · 饱腹 `#FF6B8A` 粉 · 清洁 `#4FB7FF` 蓝 · 心情 `#FFD23F` 黄

色彩纪律：
- 一页只有 `candy_pink` 一个主强调色；蓝/绿/黄只做功能辅助，不抢戏。
- 场景背景（浮空岛插画）已经很花，UI 面板必须高不透明度的 `cream` 托底，禁止半透明毛玻璃直接压在场景上。

## 3. 形状体系

| 元素 | 圆角 | 说明 |
|---|---|---|
| 弹窗/大面板 | 32px | 全游戏统一 |
| 卡片/小面板 | 24px | |
| 按钮（pill） | 全圆角（高度一半） | 文字按钮一律胶囊形 |
| 图标按钮/FAB | 正圆 | |
| 进度条 | 全圆角 | 槽与填充同圆角 |

**糖果按钮的"厚度"**：所有彩色 pill 按钮底部带 4px 深色边（如粉按钮底边 `candy_pink_dark`），营造软糖立体感。按下时按钮整体下移 4px、底边消失——这是全游戏唯一的按压语言，所有按钮必须一致。

## 4. 字体与字号

当前使用引擎默认字体（后续可替换为站酷快乐体/圆体类授权字体，接口不变）：

| 层级 | 字号（1920×1080 画布单位） | 颜色 |
|---|---|---|
| 大标题（弹窗标题/游戏名） | 46 | `ink` |
| 正文/按钮文字 | 30 | 按钮上为 `#FFF9EF`，面板上为 `ink` |
| 辅助说明 | 24 | `ink_soft` |
| 倒计时数字 | 56（`lemon`，可加 2px `ink` 描边） | |

按钮文字永远单行，禁止换行；标签超过 6 个汉字就缩写。

## 5. 组件规范

### 5.1 糖果按钮（主按钮）
- 尺寸：高 88px，水平内边距 56px，最小宽 240px；触摸热区即按钮本体（≥96px 高）。
- 结构：pill 填充 `candy_pink` + 底部 4px `candy_pink_dark` 边 + 白字。
- 按压：整体 y+4、底边隐藏；松开后 Tween 回弹（0.12s 压下，0.18s 弹回，`TRANS_BACK` + `EASE_OUT`）。

### 5.2 图标 FAB（相机）
- 正圆，直径 120px；`cream` 底 + 6px `candy_pink` 描边 + 居中 icon（icon 占直径 55%）+ 右下软投影（`shadow_warm`，y 偏移 6px）。
- 按压：缩放到 0.88 再弹回（同 5.1 时序）。
- 位置：右下安全区内，距边 40px。

### 5.3 弹窗（consent / confirm / processing / error）
- 宽 760px（内容多时 860px），`cream` 底，32px 圆角，投影 `shadow_warm`。
- 顶部 12px 彩色"糖霜条"：主流程用 `candy_pink`，错误用 `danger`，处理中用 `sky`。
- 出现动画：scale 0.8 → 1.0 + 透明度 0 → 1，0.25s `TRANS_BACK`。
- 背后压暗：全屏 `#5B4A3F @ 35%`。
- 按钮组：主按钮在右（糖果按钮），次按钮在左（`cream_dark` 底 + `ink` 字，无底边）。

### 5.4 状态条（右上四条）
- 单条宽 220px、高 22px、全圆角；槽 `cream @ 90%`，填充为对应状态色，末端圆头。
- 左侧 28px 圆形图标点（状态色实心圆 + 白色一字简称），数值放条右侧，`ink` 24px。
- 整体托底：一块 32px 圆角 `cream @ 92%` 面板把四条状态+宠物名收拢，避免碎元素直接飘在场景上。

### 5.5 孵化进度面板
- 屏幕中下居中：一枚"蛋形"白色面板（宽 480 高 260，32px 圆角），内含：
  - 大数字进度百分比（56px `lemon` 描边字）+"孵化中"（24px `ink_soft`）；
  - 下方蓝色糖果按钮「加速 -5s」（`sky` + `sky_dark` 底边）。
- 进度到 100% 进入 hatch-ready：大数字显示 "100%"，按钮换为粉色糖果按钮「迎接破壳」（`candy_pink`），孵化必须由玩家点按触发，不得自动切换。
- 蛋在面板上方或场景巢位做 2s 周期的轻微浮动（±3px）与偶发摇晃。

### 5.6 拍照预览层（全屏取景）
- 相机画面 aspect-fill 铺满全屏（竖屏），无取景框相框；等待首帧时用 `ink` 加深色托底。
- 引导圈：细线大圆（半径 `min(宽,高)×0.32`，圆心在 y 42% 处），`cream @ 90%` 4px 描线 + 外圈 `ink` 柔光晕；提示文字「把脸放进圆圈里，保持正面」放在快门上方。
- 快门按钮：直径 130px 正圆，白底 + 粉色内环，底部居中安全区内；按压同 FAB。
- 关闭按钮：左上角安全区内，56px 圆点「×」。
- 拍照期间只绘制预览层本身，底层场景不参与重绘（性能纪律）。

### 5.7 详情弹窗（蛋 / 宠物）
- 点击蛋/宠物本体或右上状态面板打开；860×680 居中面板，`cream` 底、32px 圆角、`candy_pink` 糖霜条，背后压暗同 §5.3，出场动画同 §5.3。
- 结构（左右内边距 48px）：标题（46px `ink`）→ 副标题行（24px `ink_soft`）→ 进度区（孵化进度/亲密度，30px 标签 + 全圆角进度条）→ 四项状态条（复用 §5.4 样式）→ 底部提示行（24px `ink_soft`）。
- 进度条配色：孵化进度用 `lemon`，亲密度用 `candy_pink`；四项状态条维持固定四色。
- 关闭：右上角 56px 圆点「×」或 Esc；打开期间屏蔽底层交互。
- 蛋版内容：蛋种类、到家天数、孵化进度与预计时间、四项状态、照护提示。
- 宠物版内容：物种名、亲密度等级与升级进度、相伴天数与破壳日期、四项状态、外貌/动作状态。

## 6. 动效规范

| 场景 | 参数 |
|---|---|
| 按钮按压 | 压缩 0.88，0.12s；回弹 0.18s `TRANS_BACK/EASE_OUT` |
| 弹窗出现 | scale 0.8→1 + fade，0.25s `TRANS_BACK` |
| 面板/按钮入场 | 自下而上 20px + fade，0.3s，依次延迟 0.05s |
| 待机浮动 | sin 浮动 ±3px，周期 2s（仅蛋与 FAB 允许常驻微动） |
| 孵化瞬间 | 蛋 scale 1→1.15→0 碎裂感 + 宠物 pop 出现（0.35s） |

- 只动 `scale`/`position`/`modulate`，不做耗性能的逐帧重排。
- 同屏常驻循环动画不超过 2 处。
- 所有 Tween 用 `create_tween()`，节点销毁前 `kill_tween`。

## 7. 布局与适配

- 基准画布 1920×1080，stretch `canvas_items + expand`；**禁止写死 1920/1080**，一律读 `get_viewport().get_visible_rect().size`。
- 四角元素（标题组、状态面板、相机 FAB）贴安全区（`DisplayServer.get_display_safe_area()` 换算），内距 ≥ 40px（画布单位）。
- 栅格：间距取 8 的倍数（8/16/24/40/56）。
- 触摸目标 ≥ 96px；相邻可点元素间距 ≥ 24px。
- 横屏锁定（sensor landscape）。超宽屏（>2:1）两侧多出的画布只展示场景，UI 不拉伸、不新增列。

## 8. Do / Don't

**Do**
- 所有新组件先查本文档的 token，禁止发明新颜色。
- 文案口语化、短：「加速 -5s」「使用这张」「重拍」。
- 错误提示给下一步动作（如"检查网络后重试"按钮）。

**Don't**
- 不用纯黑/纯白；不用无色相投影；不用直角；不用渐变文字。
- 不加第 7 种状态色；不在主界面加第二个粉色大按钮。
- 不用 emoji 代替 icon；icon 只用 `assets/ui/` 下的素材。
- 常驻动画不超过 2 处；不做扫光、粒子雨等炫技效果。
